
# Predicción de Consumo Energético Industrial

Trabajo Práctico Final 2026 — Laboratorio de Datos II.

## Objetivo

Predecir el consumo energético diario del sistema
de refrigeración de una planta cervecera para el
día siguiente.

## Tecnologías

- Python 3.12
- Pandas y NumPy
- Scikit-learn
- XGBoost
- LightGBM
- Git y GitHub

## Instalación

Crear y activar el entorno:

```bash
conda create -n cervecera_env python=3.12
conda activate cervecera_env
python -m pip install uv
uv pip install -r requirements.txt
```

## Datos

Los archivos Excel originales no están incluidos
en el repositorio.

Deben colocarse en la carpeta `data/`.

## Ejecución

Las instrucciones para ejecutar el EDA,

durante el desarrollo del proyecto.
